# Signaler une faille

Ce dépôt est public, le site qu'il fait tourner est privé.

Si vous trouvez une faille, ne l'exposez pas dans un ticket ou une pull request publique.
Utilisez le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**.
Les admins répondent sous sept jours.

Le scan actif (ZAP) ne vise que l'environnement éphémère de la CI. Merci de ne pas tester le site en production.
